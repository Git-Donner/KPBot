## 背景与问题

KPBot 已具备性能采集、基准测试、统计比较和优化报告能力，但现有可视化能力主要服务于特定场景。用户需要对不同指标、多个配置及重复实验结果绘图时，仍需临时整理数据和编写绘图代码。

本 PR 新增 `benchmark-visualization` 技能，支持 Agent 根据自然语言要求整理数据、配置图表并生成本地产物。用户可继续要求修改坐标范围、统计方式、分组或图型，无需直接修改绘图代码。

## 主要能力

### 1. 自定义指标与多维比较

支持用户指定指标列、单位、换算系数和样本层级，适用于耗时、吞吐、资源占用、微架构指标及其他数值数据。

系列数量根据输入动态确定，支持多个字段组合分组和分面，不限定固定指标或固定对照组数。

### 2. 通用图表与参数调整

支持：

- 散点图、折线图、点估计图。
- 分组柱状图、箱线图。
- 直方图、经验累积分布图（ECDF）。
- 热力图及多子图布局。

用户可配置坐标轴范围、尺度、标题、颜色、图例、图大小和导出分辨率。支持 SVG、PNG 和 PDF 输出。

### 3. 重复实验及统计口径

支持均值、中位数、最小值、最大值、样本标准差、MAD 和指定分位数。

对于重复观测，折线、点估计和柱状图在未指定范围时自动补充 min/max；热力图额外生成观测散点图，避免仅以单个聚合值掩盖波动。

区分独立运行、运行内采样及已有汇总值。已有汇总再次聚合需要显式声明，不从 min/max/median 还原不存在的原始分布，也不将描述性范围解释为置信区间。

### 4. 多文件输入与数据整理

支持 CSV、TSV、JSON 和显式声明格式的分隔文本，允许通过输入列表读取多个文件，并添加文件级分组字段。

SKILL 将数据盘点和 reshape 放在绘图之前。异构表格或自由文本日志由 Agent 按实际结构整理为标准记录，保留来源和转换说明；本 PR 不提供通用日志解析器。

### 5. 长标签和多轮修改

长类别横轴名称自动使用 A/B/C 等代号，并保留完整名称映射。

允许多次绘图保存到同一目录，通过用户指定名称或自动前缀区分图表、数据、配置和报告，避免覆盖已有结果。

### 6. 无多模态 Agent 支持

Agent 不具备读图能力时，仅执行数据、配置和产物检查，并明确提示用户进行视觉复核。不会要求 Agent 必须读取图片，也不会将文件生成成功表述为视觉审核通过。

## 使用位置与产物

本技能在性能采集、benchmark 或统计结果产生后使用，也可独立接受用户提供的数据。

输出包括：

- 本地图表文件。
- 每幅图使用的数据 CSV。
- 统计摘要和绘图配置。
- 输入来源及工具版本记录。
- Markdown 图表索引。

产物可由现有优化报告或 Reviewer 引用。技能负责呈现数据，不自动判定优化是否正确、显著或应被接受。

## 使用示例

> 请比较这几个版本的耗时，用散点显示每次独立实验，并叠加中位数。按输入规模分面，保留全部有效样本。

后续修改：

> 将纵轴范围扩大到 0—200 毫秒，保留旧图，在同一目录另存新版。

也可以要求更换指标、增加分组维度或切换图型，Agent 通过修改配置重新生成产物。

## 验证情况

本地 12 项自动测试通过，覆盖：

- 动态分组、分面和统计计算。
- 重复实验编号及已有摘要的处理。
- 多文件读取、长表过滤和单位换算。
- 缺失矩阵单元。
- 图型生成、自定义坐标范围。
- 长标签映射、同目录重绘及旧产物保留。
- Claude Code/OpenCode 两种技能目录布局下的脚本运行。

同时生成了合成示例图和两版纵轴调整结果。

上述验证属于程序回归及模拟验证，不等同于 Agent 端到端验收。目前尚未完成官方 `case-spec.md` 所定义的 with/without Agent 对照、Skill 调用 trace 留存及完整安装回归。

## 当前边界

- 不提供自动显著性检验或优化收益归因。
- 不支持从汇总值恢复原始样本。
- 自由文本日志需要 Agent 先整理。
- 双轴、小提琴、堆叠、Gantt 和自动下采样暂未实现。
- 真实业务数据适配和用户 Agent 端到端验证仍需补充。

希望维护者重点评审技能定位、输入输出契约及与现有报告流程的衔接方式。
