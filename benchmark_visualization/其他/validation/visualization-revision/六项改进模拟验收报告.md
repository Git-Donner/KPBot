# 绘图 SKILL 六项改进模拟验收

日期：2026-11-05。全部修改位于 KPBot-zl，未修改 KPBot-master。

## 验证方式与边界

本轮使用明确标注的模拟数值，完成流程指令检查、程序自动测试和实际文件生成。共 12 项自动测试通过，包括原有回归以及新增六项改进场景。

没有连接用户自己的 Agent，不能声称完成外部 Agent 的端到端验收。reshape 和无多模态分支以提示流程及模拟输入输出核验；本轮没有要求无多模态 Agent 打开图像，也不将文件生成成功解释为视觉效果通过。

## 1. 数据先整理/reshape

模拟输入：raw/baseline.csv 为每轮一列的宽表；raw/candidate.txt 为带说明文字的日志。两个文件结构不同，不能直接拼接。

模拟用户请求：

> 这两个文件是基线和候选的三次独立实验，请比较耗时并画图。

Agent 应先盘点文件、确认单位和轮次，再将宽表转逐轮行、TXT 提取为标准表，保留原文件。不能把此任务默认推给上游，不能要求用户必须先合成一个 CSV。

本轮用手工明确列出的标准化测试夹具模拟整理结果，位于 prepared/；没有新增通用 reshape 程序。baseline 的 10/15/20 和 candidate 的 11/17/24 分别与原文件一一对应，每侧三行。SKILL 第一步及 data-preparation.md 已明确这项职责，自动测试确认其位于绘图步骤之前。

结论：流程约束及整理后输入验证通过；用户 Agent 实际解析异构文件能力需用上述请求另行端到端验证。

## 2. 无多模态输入

模拟用户条件：Agent 仅能读文本和操作文件，没有图像读取能力。

预期行为：核对统计、数据数目、配置和输出路径后交付，明确图片待用户检查；不调用图像工具，不声称已看图，不阻塞绘图。

实现：SKILL 按能力分支；data-preparation.md 明确非视觉检查范围；输出索引包含用户视觉审核提示。自动测试检查提示存在。

用户仍需检查轴范围、标签/全称映射、图例和裁切。该分支验证通过的是提示及文件行为，不是视觉审核本身。

## 3. 同目录多次修改

模拟请求：先按默认范围画图，再把纵轴扩大至 0—100 ms，保留旧图。

实际运行 v1.json 和 v2.json，均输出到 plots/。产物名称分别为：

- figures/v1-latency.svg、figures/v1-latency.png。
- figures/v2-latency.svg、figures/v2-latency.png。
- v1-index.md、v2-index.md，以及各自的配置、摘要、来源记录和 CSV。

自动测试确认旧图字节不变，两版 CSV 相同，显式重复 run_name 会报错，省略 run_name 时已有目录自动使用新前缀。不再要求每次使用不同目录。

结论：通过。

## 4. 长标签

模拟测试用例名：query_case_with_very_long_name_large_dimension_and_multiple_compiler_options。

预期：横轴使用 A，完整名称仍在图旁说明和报告中，数据里的原名不改变。

实现：类别横轴名称超过默认 24 字符时自动生成 A/B/.../AA；支持自定义 label_map 和阈值。摘要及索引保存完整映射，图侧展示前 12 项，更多项目查完整附表。

自动测试检查完整名称到 A 的映射及索引保留全名；图文件已生成。图例、分面等其他长名称由 Agent 按 SKILL 指引进一步提炼，当前自动编码主要覆盖类别横轴。

结论：映射与文件生成通过，视觉可读性交用户检查。

## 5. 重复实验波动

配置故意只声明 aggregate=mean，没有手工指定 spread。基线样本 10/15/20，候选 11/17/24，各为三次独立运行。

预期：不能只显示两个平均值。程序自动补充 minmax 范围，基线为 [10,20]，候选为 [11,24]；样本数均为 3。

实现：重复观测的 line/point/bar 默认补 minmax；散点、箱线、直方图和 ECDF 展示观测/分布；重复观测热力图额外生成 -samples 散点图。已有汇总缺少离散程度时 SKILL 要求明确缺失，不能虚构。

自动测试检查范围数值、样本数和伴随图数量。范围属于描述性 min/max，不称为方差或置信区间。

结论：通过。

## 6. 多文件、多格式

实际配置使用 inputs 数组，同时读取 prepared/baseline.csv 和 prepared/candidate.csv，并分别添加文件级 version 维度。另一个自动测试直接将具有 CSV 内容的 .txt 文件以 format=csv 读取。

程序合并六条观测，保留每条 source_file/source_record，以及两份输入的 SHA-256。文件维度与已有记录冲突时报错，不静默覆盖。不同分隔符可配置 delimiter。

原始自由文本 TXT 不冒充普通 CSV：先按第 1 项整理。多个文件字段不同、单位不同或需要关联时，由 Agent 在前置步骤按真实结构处理，不依赖固定文件名或固定组数。

结论：同构多文件与显式文本格式读取通过；任意日志语义解析由 Agent 按提示完成。

## 产物查看

先查看 plots/v1-index.md 与 plots/v2-index.md。图表保存于同一个 figures 目录。所有数值仅用于模拟验收，不代表真实服务器性能。

## 复现命令

在 KPBot-zl 根目录、已安装 Matplotlib 的环境执行：

```bash
python -B -m unittest discover -s tests -p test_benchmark_visualization.py -v
python Plugins/code-optimizer/skills/benchmark-visualization/scripts/visualize.py --spec validation/visualization-revision/v1.json --output-dir validation/visualization-revision/new-plots
python Plugins/code-optimizer/skills/benchmark-visualization/scripts/visualize.py --spec validation/visualization-revision/v2.json --output-dir validation/visualization-revision/new-plots
```

两个绘图命令故意使用同一个目录。再次执行相同 v1/v2 名称时应更改 run_name，避免覆盖。
