# 通用性能图表

## 输入

已有测量文件、指标列与单位、样本层级，以及用户希望比较的维度。上游可以是 benchmark、性能采集、验证结果或用户提供的表格。本技能在数据产生后使用，输出供用户、优化报告及 Reviewer 查看。

## 执行步骤

1. 读取列名和少量样本，确认哪些列是指标、维度、独立实验编号或现成统计值。按 [数据契约](references/data-contract.md) 建立配置，不按场景写死指标。
2. 根据用户问题选择图型、横轴、系列和分面；用户已有选择时直接采用。多个系列/分面维度可组合，不限制组数。参见 [图表选择](references/chart-selection.md)。
3. 明确单位与统计层级。重复实验使用独立运行编号；一个运行中的多次采样应先按需要汇总，不能自动视为更多独立实验。参考 [统计规则](references/statistics-rules.md)。
4. 保存配置，使用 `python scripts/visualize.py --spec <配置文件> --output-dir <新输出目录>` 生成图。脚本路径相对于本 SKILL，输入相对路径相对于配置文件。
5. 检查图表中的标签、单位、系列、裁切和数据点，核对 summary 与原始输入。发现错误时修改配置并重新渲染。
6. 返回图表预览或文件链接、`index.md`、绘图配置和数据路径。后续调整复用 `chart-spec.resolved.json`，例如扩大纵轴只修改对应 chart 的 `ylim`，再指定新输出目录。

## 输出

SVG/PNG（可选 PDF）、逐图数据 CSV、统计摘要 JSON、可复用绘图配置、输入与工具身份记录，以及 Markdown 图表索引。图表是主要交付物；依赖缺失或渲染失败时不能把仅有的数据文件称为完整交付。

## 依赖

Python 3.10+、Matplotlib 3.6+（包含 NumPy 依赖）。使用目标环境已有依赖；需要安装时遵循当前环境的安装权限。

## 约束

保留所有选中样本，过滤条件进入配置。不存在的组合不补零。不得从 min/max/median 还原分布，不把各轮 P99 的聚合称为总体请求 P99。图表用于呈现数据，不自动证明优化显著、可比或正确。

本版支持结构化数据和向量原始结果适配；专有日志先交由对应采集/解析技能处理。没有自动配对检验、置信区间、任意公式执行或收益归因。
