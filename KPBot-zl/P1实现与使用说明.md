# P1 通用性能图表实现与使用说明

## 交付位置

技能位于 `Plugins/code-optimizer/skills/benchmark-visualization`。`KPBot-zl` 仍是增量文件集合，需按同名相对路径合入完整项目再使用其安装脚本；没有修改 `KPBot-master`。

入口为 `SKILL.md`，代码入口为 `scripts/visualize.py`。当前按单文件组织可执行逻辑，内部划分数据读取、校验、统计、渲染和交付函数；避免多个同名 statistics 模块与标准库冲突。

## 已实现能力

- CSV、TSV、JSON 记录数组及嵌套数组；P0 向量原始输入适配。
- 用户自定义指标列、单位、换算系数与样本粒度。
- 任意数量系列，多个维度组合为 series/facet；动态分面布局。
- 散点、折线、点估计、分组柱状、箱线、直方图、ECDF、热力图。
- mean、median、min、max、count、样本标准差、MAD 和自定义分位数。
- min/max、IQR、mean±SD、median±MAD 描述性范围。
- 原始重复实验点叠加，重复实验编号检查，现成统计值再次聚合的显式确认。
- xlim/ylim、尺度、图大小、分辨率、颜色、点大小、线宽、图例和标题等配置。
- SVG/PNG/PDF，逐图数据、统计摘要、配置和来源记录。

输入数据没有固定指标名、固定组数或固定维度数量。时间/吞吐/IPC 仅作为合成示例。长表通过 filter 选择指标，宽表通过 mapping.metrics 选择列。

## 运行示例

环境需要 Python 3.10+ 和 Matplotlib。当前工作区验证用依赖安装在 `D:/workspace/KPBot/.plot-deps`，不属于交付技能；正式环境应使用自身的 Python 依赖。

在技能目录运行：

```bash
python scripts/visualize.py --spec assets/examples/chart-spec.json --output-dir /path/to/new-output
```

配置相对输入路径以配置文件目录为基准。再次绘图指定新输出目录，避免覆盖此前结果。

完整示例配置见 `assets/examples/chart-spec.json`，合成数据包含三个对照组、两个硬件分面、四个线程档和五次重复实验，分别绘制时间、吞吐和 IPC。

本次实际生成的八类图及其数据位于 `examples/benchmark-visualization-verified/`，通过其中的 `index.md` 查看。图中为合成数值，不代表真实硬件性能。

## 常见调整

### 拉大纵轴范围

在对应 charts 对象中设置：

```json
"ylim": [0, 100]
```

仅固定下限：`"ylim": [0, null]`。参数改变后重新运行，无需修改 Python。

### 增加对比组与维度

数据增加新的 version 值即可自动增加系列；不需要修改颜色数量或代码。需要按版本和编译器共同分组时：

```json
"series": ["version", "compiler"],
"facet": ["machine", "dataset"],
"columns": 3,
"figsize": [21, 10]
```

增加维度后，同组若出现多个 x 观测，应选择 aggregate 或把运行编号加入 series，不静默混合。

### 更换指标或统计方式

在 mapping.metrics 声明新列，然后将图的 metric 指向对应 name。可以使用 `aggregate="min"`、`"max"`、`"median"` 或 `"p95"`，也可取消聚合绘制所有散点。

现成统计值标记 `sample_level="summary"`。对这些值再次聚合时使用 `aggregate_summary=true`，标签说明这是“各轮统计量”的再聚合。

## 上下游接入

已有 benchmark 或采集工具先产生结构化数据，再调用本技能；报告和 Reviewer 使用生成的图表附件。P0 的技能说明中已增加可选图表调用指引。

TF 的 CSV 可直接映射 actual_qps、p99_latency_us、server_cpu_pct_avg 等列；对照身份由用户声明，不能从 opt/baseline 文件名推测。app-tuner 的结构化记录也可经列映射使用。当前未修改其主编排器或整体报告 schema。

完整项目安装器按 skills 目录复制，本技能使用两平台共用文件。新增目录合入后原 72 个代码优化技能变为 73 个，OpenCode 原 70 个变为 71 个；发布时需同步完整项目的数量说明。

## 验证结果

新增 10 项测试全部通过。测试覆盖动态分组和分面、统计口径、独立实验编号、现成摘要、长表过滤和换算、缺失矩阵单元、向量输入适配、八种图型及纵轴范围。

已查看八类图表的实际渲染，包括折线范围、热力图、散点、箱线、柱状、点估计、直方图与 ECDF；修复了热力图标签被重置的问题。当前视觉检查基于合成示例，真实业务数据仍需按其维度和标签长度复核布局。

## 当前边界与后续工作

通用核心和参数调整已实现；计划中的自动可比性推导、对任意 P0 输出摘要的专用适配、失败/预热状态自动分类、派生指标公式、完整安装回归及真实场景验收仍需后续补充。现成统计可用表格方式绘制，不自动还原样本。

不支持双轴、按第三指标映射气泡大小、小提琴、堆叠、Gantt、自动置信区间及下采样。时间字符串目前按类别处理；数值时间可设 x_type=numeric，ISO 时间的自动日期轴为后续扩展。

人工指定坐标范围可能裁切数据，应检查最终图。默认全部观测参与计算与绘图，不静默排除慢样本。图表表达测量结果，不自动证明优化有效或正确。
